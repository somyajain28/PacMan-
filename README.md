# PacMan Game 🎮

A classic PacMan arcade game developed using **Java** and **Java Swing**. The game allows players to control PacMan through a maze, collect food pellets, avoid ghosts, and achieve the highest possible score while managing limited lives.

## 📌 Features

- **Player Movement:** Control PacMan using the arrow keys (Up, Down, Left, Right).
- **Ghost Enemies:** Four different ghosts (Red, Pink, Blue, and Orange) move around the maze.
- **Food Collection:** Collect food pellets to increase your score.
- **Collision Detection:** Wall collisions prevent PacMan and ghosts from passing through walls.
- **Scoring System:** Earn 10 points for every food pellet collected.
- **Lives System:** Start with 3 lives. Lose a life whenever a ghost catches PacMan.
- **Game Over:** The game ends when all lives are exhausted.
- **Restart Option:** Press any key after Game Over to restart the game.

## 🛠️ Technologies Used

## 🕹️ Gameplay

1. Start the game and navigate PacMan through the maze.
2. Collect all the food pellets to earn points.
3. Avoid collisions with ghosts to preserve your lives.
4. Complete the maze to reset the level.
5. Try to achieve the highest score!
